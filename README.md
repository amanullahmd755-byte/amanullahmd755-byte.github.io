# 🌟 MD Amanullah - AI & ML Engineer Portfolio

A sleek, responsive, and modern personal portfolio website built for **MD Amanullah**, showcasing his academic background, skills in **AI & Machine Learning**, certifications, and projects. Designed with a dark-to-warm gradient theme, clean typography, interactive PDF modal previews, and smooth dark/light mode switching.

---

## 🎨 Design Highlights & Features

- 🌙 **Dark / Light Mode Toggle:** Smooth theme switcher with localized preference saving using `localStorage`.
- 📄 **In-App PDF Modal Previews:** View certificates and resume directly on the site via an interactive overlay window without opening new tabs.
- 📱 **Fully Responsive Layout:** Optimized for mobile phones, tablets, laptops, and ultra-wide screens.
- 📬 **Interactive Contact Form:** Instant mailto integration sending messages directly to `amanumd041@gmail.com`.
- ⬆️ **Floating Back-to-Top Button:** Pure SVG animated button for smooth page navigation.
- 🎨 **Visual Section Hierarchy:** Alternating background shades and glowing accent borders for clean scannability.

---

## 🛠️ Built With

* **HTML5:** Semantic layout structure.
* **CSS3:** Custom CSS variables, flexbox grid, glassmorphism overlays, and dark-to-warm radial gradients.
* **JavaScript (ES6):** Modal pop-up logic, active link detection, theme state persistence, and smooth scrolling.
